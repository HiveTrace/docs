Раздел **«Проверка языка»** позволяет контролировать язык запросов и ответов: задать список разрешённых языков и выявлять текст на посторонних языках. 

## Как открыть раздел **Проверка языка**

1. В боковом меню выберите **Приложения**.
2. Откройте нужное приложение, нажав на карточку или на название приложения в зависимости от выбранного вида отображения.
3. Наведите на вкладку **Защита**.
4. Нажмите на **Проверка языка**.

![Переход в раздел Проверка языка](../../../../assets/img/language-redirect-4-4.webp)

В верхней части страницы отображаются название, id, описание (при наличии) приложения. Рядом с ID доступна кнопка копирования. На странице также доступна ссылка `«Назад к приложениям»`, которая ведёт в раздел `Приложения`.

## Редактирование приложения

![Редактирование приложения](../../../../assets/img/language-edit-app-4-4.webp)

1. Нажмите `«Редактировать»`.
2. Измените нужные поля.
3. Нажмите `«Сохранить»`.

## Удаление приложения

![Удаление приложения](../../../../assets/img/language-delete-app-4-4.webp)

1. Нажмите `«Удалить»`.
2. Подтвердите удаление в окне подтверждения.

Удаление необратимо. Сначала убедитесь, что интеграционный трафик остановлен или перенаправлен и связанные API-токены больше не используются.

## Профиль

Если профиль выбран, отображается его название. Если профиль не выбран — действуют индивидуальные настройки. При изменении настроек защиты приложения оно отвязывается от профиля, а текущие настройки переходят в индивидуальные.

Обновить профиль можно на странице: 
1. Нажмите кнопку `«Профиль»`.
2. Выберите нужный профиль из списка. Поле поиска помогает быстро сократить список.
3. Подтвердите привязку профиля к приложению в окне подтверждения.

![Профиль в разделе Проверка языка](../../../../assets/img/language-profile-4-4.webp)

## Разрешённые языки

В разделе доступны следующие языки: `Английский`, `Арабский`, `Армянский`, `Белорусский`, `Грузинский`, `Иврит`, `Казахский`, `Русский`, `Турецкий`, `Украинский`

Чтобы разрешить язык, отметьте его чекбокс; можно выбрать один язык или несколько — вплоть до всех.

![Список разрешённых языков](../../../../assets/img/language-allowed-languages-4-4.webp)

## Проверка запросов и ответов

Проверки для входящих и исходящих сообщений включаются отдельно.

> **Примечание:** чтобы перевести переключатель проверки запросов или ответов в активное состояние, необходимо выбрать хотя бы один язык.

![Переключатели запросов и ответов](../../../../assets/img/language%20-switches-4-4.webp)

## Порог

Порог задаёт допустимую долю букв из других систем письма, при которой текст ещё не считается нарушением. Его можно установить от `0%` до `100%`: чем ниже значение, тем строже проверка — при `0%` любая чужая буква приводит к нарушению. Смешанный текст проверяется с учётом этого порога: пока доля посторонних букв не превышена, нарушение не фиксируется.

Сбросить установленный порог можно кнопкой `«Сбросить порог»` или с помощью переключателя. После сброса поле порога возвращается к значению по умолчанию — `25%`, а переключатель становится неактивным. Нажмите `Сохранить`, чтобы применить изменения.

![Порог допустимых букв из других систем языка](../../../../assets/img/language-threshold-4-4.webp)

## Доступ к странице

Для редактирования приложения из шапки нужны права:

- Область **Приложения** — уровень доступа не ниже `«Редактирование»`.

Для удаления приложения из шапки нужны права:

- Область **Приложения** — `Полный` уровень доступа.

Для просмотра настроек проверки языка нужны права:

- Область **Приложения** — уровень доступа не ниже `«Чтение»`;
- Область **Политики приложения** — уровень доступа не ниже `«Чтение»`.

Для редактирования настроек проверки языка нужны права:

- Область **Приложения** — уровень доступа не ниже `«Чтение»`;
- Область **Политики приложения** — уровень доступа не ниже `«Редактирование»`.

Для обновления профиля приложения нужны права:

- Область **Приложения** — уровень доступа не ниже `«Редактирование»`;
- Область **Политики приложения** — уровень доступа не ниже `«Редактирование»`;
- Область **Профили защиты** — уровень доступа не ниже `«Чтение»`.

Если у пользователя нет доступа для просмотра страницы, отображается страница `403 - Нет доступа`.
