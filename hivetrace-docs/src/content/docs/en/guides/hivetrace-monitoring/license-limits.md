Open **License and limits** from the profile menu to review the license status, expiration date, and message usage.

![License status and message limit](../../../../../assets/img/license-limits-4-3.webp)

The message counter shows used messages against the available total, while the progress bar visualizes the consumed share. Values in the screenshot are examples; use the values displayed in your environment. Contact the responsible administrator before the license expires or the limit is reached. Select **×** to close the dialog.
