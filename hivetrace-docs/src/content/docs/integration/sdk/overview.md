SDK HiveTrace подключает мониторинг запросов, ответов модели, файлов и вызовов инструментов к Python-приложениям. Доступны синхронный `SyncHivetraceSDK` и асинхронный `AsyncHivetraceSDK`; оба клиента работают как контекстные менеджеры.

## Возможности

- `input()` — анализ запроса пользователя и опциональных файлов;
- `output()` — анализ ответа модели и опциональных файлов;
- `function_call()` — регистрация вызова инструмента и его результата;
- `additional_parameters` — произвольные JSON-метаданные сессии, пользователя или агента;

Клиенты возвращают Pydantic-модели ответа. Для получения словаря используйте `result.model_dump()`.

## Конфигурация

Базовые клиенты читают `HIVETRACE_URL` и `HIVETRACE_ACCESS_TOKEN`. `application_id` передаётся в каждый вызов явно.
